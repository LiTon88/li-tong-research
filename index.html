Abstract

Continuous aerial pick-and-place requires whole-body planning across ordered grasping and placement events while respecting the non-Euclidean configuration manifold of the aerial manipulator. This paper presents a manifold-aware spatio-temporal planning framework based on discrete right-trivialized Hamiltonian dynamics. A discrete Hamiltonian variational formulation on SE(3) × ℝn provides a manifold-consistent dynamics transcription, while continuous task-progress variables and relaxed event-complementarity constraints encode multiple ordered events without integer variables or predefined event nodes. The resulting nonlinear program jointly optimizes the whole-body trajectory, maneuver duration, and event timing while accounting for control smoothness and payload clearance. In a multi-waypoint aerial-locomotion benchmark, the proposed formulation retains feasibility on the tested coarse grids and requires less solve time than fourth-order Runge-Kutta and discrete Euler-Lagrange transcriptions in the reported large-scale cases, while yielding comparable maneuver durations. Experiments on an aerial manipulator with a 3-DoF arm demonstrate a continuous pick-transport-place maneuver with onboard contact detection, disturbance observation, and admittance filtering.

The framework contains three coupled components. First, a discrete variational model provides structure-preserving system dynamics. Second, the spatio-temporal optimal control problem solves the motion and total duration simultaneously. Third, relaxed complementarity constraints coordinate ordered contact events through continuous progress variables. This unified construction enables feasible and efficient grasping motion to be generated within a finite planning horizon.
