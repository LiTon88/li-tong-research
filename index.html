Abstract

Dynamic aerial grasping requires simultaneous reasoning about nonlinear flight dynamics, manipulator motion, contact events, and task timing. We formulate these coupled decisions in a unified spatio-temporal trajectory optimization problem. Discrete variational mechanics is employed to preserve the mechanical structure of the aerial manipulator, while relaxed complementarity constraints describe grasp events and task progress in a differentiable form. The resulting planner jointly optimizes system states, control inputs, event progress, and motion duration. The framework is integrated with closed-loop control and experimentally evaluated through pick-and-place operations on a 3-DOF aerial manipulator.

The framework contains three coupled components. First, a discrete variational model provides structure-preserving system dynamics. Second, the spatio-temporal optimal control problem solves the motion and total duration simultaneously. Third, relaxed complementarity constraints coordinate ordered contact events through continuous progress variables. This unified construction enables feasible and efficient grasping motion to be generated within a finite planning horizon.
